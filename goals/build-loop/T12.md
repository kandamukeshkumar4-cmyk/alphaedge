# T12 — Public API for the future UI (the UI-loop contract)

Spec: docs/project/BUILD_LOOP_BACKEND.md §3 T12. Branch: (shared tree).

## Design (first-principles)

What must be true:
- These endpoints ARE the contract the UI-build loop consumes. Stable shapes,
  paginated, bounded, honest empty states, no auth for reads (public track record is
  the whole point). Rate limiting is already global (SlowAPIMiddleware) — no per-route
  decorator needed; a rate-limit header presence test suffices.
- Pagination must be bounded (limit ge/le, offset ge) so a client can't request an
  unbounded page. Return total so the UI can page.
- Track record reads from T08 analyst_eval_aggregates (recomputed hourly), including
  per model_version / prompt_version dimensions — the "per-version" transparency.
- The claims feed exposes graded claims (correct/incorrect/void) — honesty: show the
  misses, not just wins.
- Latency badge = price freshness: last snapshot captured_at + staleness seconds +
  source (an honest "how far behind" proxy without a queryable live stream-state).

Derived approach:
- `schemas/analyst_api.py` (pydantic response models): CitationOut, ClaimOut,
  BriefOut, BriefListOut, AggregateOut, TrackRecordOut, ClaimListOut, LatencyOut.
- `api/v1/briefs.py` (APIRouter prefix /api/v1):
  - GET /briefs — limit(20, 1..100)/offset(≥0), filters market/category(join Market)/
    kind; order created_at desc; returns {items, total, limit, offset}.
  - GET /briefs/{brief_id:UUID} — brief + its claim; 404 if missing.
  - GET /analyst/track-record — filters window_days/dimension; groups aggregates
    incl. per-version; empty → {aggregates: []}.
  - GET /analyst/track-record/claims — limit/offset, filter status/market; graded
    claims newest-first; {items, total, limit, offset}.
  - GET /markets/{slug}/latency — last snapshot captured_at, staleness_seconds,
    source; honest empty when no snapshot.
- Register router in main.py.
- Tests: pagination bounds (422 out-of-range), empty states, filters (market/kind/
  category/status), brief-by-id 404 + found-with-claim, track-record shape,
  latency shape, rate-limit header present.

Guardrail: read-only public endpoints; no order path; no auth needed (public track
record). No schema change (DB). PASS.
